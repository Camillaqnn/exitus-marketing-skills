# Skills do Claude — Marketing Exitus

Cópia das skills personalizadas usadas no Claude pelo marketing do Exitus.

## Estrutura

- `skills/` — uma pasta por skill, cada uma com seu `SKILL.md` (e `references/` ou `CHANGELOG.md` quando houver)
  - `exitus-*` — fluxo de ciclos de postagem (copy, banco de copys, pauta, ajustes), fluxo de demandas (brifar, organizar, confirmar) e voz e marca
  - `mega-brain` — criação e diagnóstico de prompts
  - `gerador-prompts-imagem` — prompts de imagem com IA
  - `content-humanizer` — skill de terceiros (Alireza Rezvani, licença MIT)
- `tarefas-agendadas/` — instruções da tarefa agendada que atualiza o Calendário de conteúdo (Pauteiro)

## Observações

- As skills prontas da Anthropic (docx, pdf, pptx, xlsx, skill-creator etc.) não estão aqui: elas já vêm com a conta do Claude.
- Este repositório é uma cópia. A versão em uso continua sendo a que está instalada no Claude; ao editar uma skill, atualize os dois lugares.
