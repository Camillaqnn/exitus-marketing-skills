# Changelog — exitus-ajustes-ciclos

Mais recente no topo. Ajuste pontual (texto, regra) sobe o número depois do ponto (1.0 → 1.1); mudança de fluxo ou de etapa sobe o primeiro número (1.x → 2.0).

## 1.0 — 24/11/2026
**Adicionado**
- Primeira versão: lê o pedido de ajuste, estende para as variações da peça, propõe cada ajuste, mostra a lista numerada para o time escolher e pauta os escolhidos na caixa "Ajustes" do Calendário de conteúdo, atualizando a copy na pauta e o estágio da peça para "Ajuste".
