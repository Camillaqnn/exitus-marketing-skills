# Prompts testados — histórico da Camilla

Este arquivo guarda prompts que a Camilla efetivamente testou e aprovou (não é biblioteca teórica como `nano-banana-prompts.md` — é registro do que já funcionou na prática dela). Consultar este arquivo antes de propor um prompt do zero para um contexto parecido a algo já registrado aqui, e reaproveitar/adaptar o que já deu certo em vez de reinventar.

Formato de cada entrada:

```
## <nome curto do prompt/uso>
- Ferramenta: <ex: Nano Banana Pro, Midjourney>
- Contexto: <pra que foi usado — ex: still de produto pra campanha X>
- Prompt:
  > texto do prompt
- Resultado: <o que a Camilla observou — o que funcionou bem>
```

Quando a Camilla disser algo como "esse prompt ficou bom, salva aí" ou "guarda esse resultado", adicionar uma entrada nova aqui seguindo o formato acima. Não remover entradas antigas a menos que ela peça explicitamente.
